# Rock n' Bira Battle (playable)

A 16-bit fighting game starring legendary guitarists, presented by Rock n' Bira Open Bar. Prototype with Eddie Van Halen, Slash, Zakk Wylde and Steve Vai.

**Play:** https://espartabranding.github.io/axe-masters-play/

Fan project, non-commercial. The guitarists' names and likenesses belong to their respective owners.
